WHITE-QUAD ROOT CAUSE (exact)
src/game/Effects.ts:48-51 — the single Points system is created as `new THREE.PointsMaterial({ size: 0.5, vertexColors: true, transparent: true, opacity: 0.9, depthWrite: false, sizeAttenuation: true, blending: THREE.AdditiveBlending })` with NO `map`. A PointsMaterial without a map renders each gl_Point as a fully-covered hard SQUARE (no gl_PointCoord falloff). The colors are bright and near-neutral — boost `Color(1,0.6,0.2)×(0.7..1.2)` (Effects.ts:79-92, called from Kart.ts #visuals on every boosting frame) and dust default `(0.9,0.85,0.75)` (Effects.ts:94-102, called when drifting) — and AdditiveBlending blows them to white/cream over sky/road, with sizeAttenuation making near-camera squares huge. The dead-particle guard (`y=-999`, Effects.ts:155-159) works, so what you see are LIVE boost/dust/spinStar particles. Minimal fix (~10 lines, Effects.ts constructor): add a 64×64 radial-gradient canvas sprite — `const c=document.createElement('canvas'); c.width=c.height=64; const g=c.getContext('2d')!; const r=g.createRadialGradient(32,32,0,32,32,32); r.addColorStop(0,'rgba(255,255,255,1)'); r.addColorStop(0.4,'rgba(255,255,255,.6)'); r.addColorStop(1,'rgba(255,255,255,0)'); g.fillStyle=r; g.fillRect(0,0,64,64); const tex=new THREE.CanvasTexture(c); points.material.map=tex; points.material.alphaMap=tex; points.material.alphaTest=0.02;` and keep depthWrite:false. Optional: swap dust to NormalBlending and drive fade via opacity instead of color-multiply so flames keep orange hue instead of clipping to white.

VISUAL GAP PLAN (impact-per-effort, top 8)
1. Sprite texture + circular falloff for all particles (VS-1 fix, ~30min) — then retint flames orange→yellow with NormalBlending core + Additive halo; suddenly drift dust, sparks, and flames all read.
2. Instancing pass in track.ts: InstancedMesh for fence posts (single geometry+material), merge trees via BufferGeometryUtils.mergeGeometries (or InstancedMesh with per-instance color), merge karts' static chassis into ~3 meshes each. 500→<100 draw calls; enables stable 60 even in SwiftShader/iGPU.
3. Post chain: EffectComposer + UnrealBloomPass (threshold 1.0, strength 0.35, radius 0.6) + OutputPass, plus a speed vignette that intensifies with speed (reuse existing .vignette div, animate its radial extent with `player.speed/maxSpeed`); shield/star states get a colored screen edge. Cheap, instantly "modern fun".
4. Sky rebuild: drop circle-clouds; shader sky dome (z-gradient + 2 hard sun bands) with 8-12 stylized billboard cloud sprites drifting; set fog color = horizon color and raise density to ~0.004 for real aerial depth; derive `scene.environment` from that sky (cube→PMREM) instead of RoomEnvironment.
5. Shadow quality: make sun follow player (`sun.position = player.pos + offset; sun.target = player`), tighten ortho to ~±45, snap to shadow-texel grid to kill shimmer; add a soft blob shadow mesh under each kart so contact is stable regardless of cascade.
6. Kerb/road polish: fix squash (repeat (1,2) so cells ≈0.31×1m) or model chunky kerb segments; bake edge-AO (dark vignette band) into the asphalt texture edges; reduce splotch contrast 50% and remove flower-dot cyan (keep yellow/white only).
7. Readability package: canvas-sprite name plates (colored pill + name, scale by rank) above karts; driver animation rig — hands to a steering wheel bar, lean torso against steer, helmet turns with drift; per-kart roof stripe using accent color.
8. HUD/UI pass: styled class for result/pause buttons matching `.start`, hide race HUD in FINISHED, opaque minimap bg + road fill with casing + start-line tick, dt-based roulette with a proper 3-slot reel feel and end-snap.
